# 동네 공원 홈페이지

이 프로젝트는 지역 주민들에게 동네 공원에 대한 정보를 제공하고 공원 활동 및 이벤트를 홍보하기 위한 웹사이트입니다.

## 주요 기능

- 공원 소개 및 시설 정보
- 공원 이용 시간 및 규칙
- 이벤트 및 프로그램 일정
- 공지사항 및 뉴스
- 방문객 갤러리
- 문의 및 피드백 양식

## 기술 스택

- HTML5, CSS3, JavaScript
- 반응형 디자인
- 모던 UI/UX

## 설치 및 실행 방법

1. 저장소 클론
```
git clone [repository-url]
```

2. 프로젝트 폴더로 이동
```
cd neighborhood-park-website
```

3. 웹 서버로 실행 (예: Live Server 확장 프로그램 사용)

## 프로젝트 구조

```
/
├── index.html          # 메인 페이지
├── css/                # 스타일시트 파일
├── js/                 # 자바스크립트 파일
├── images/             # 이미지 파일
└── pages/              # 추가 페이지들
```
