## 이미지 가이드라인

- 모든 이미지는 최적화된 웹 형식(jpg, png, webp)으로 저장해주세요.
- 이미지 크기는 용도에 맞게 최적화해주세요.
  - 배경 이미지: 최소 1920x1080px
  - 갤러리 이미지: 800x600px 권장
- 이미지 파일 크기는 웹 성능을 위해 최대한 작게 유지해주세요.
- 모든 이미지는 저작권에 문제가 없는 이미지를 사용해주세요.
